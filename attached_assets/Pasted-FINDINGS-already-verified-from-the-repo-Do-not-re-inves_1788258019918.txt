PHASE A — Chat bubble
A1. Portal it to document.body

Wrap both the launcher and the panel in createPortal(..., document.body).

Rationale: any ancestor with transform, filter, backdrop-filter, perspective, contain or will-change silently makes position: fixed resolve against that ancestor instead of the viewport. Portalling removes the whole class of problem permanently.

A2. Keep it bottom-right — but anchor it to the viewport properly

The launcher stays in the bottom-right corner. Its classes already say bottom-6 right-6, so the corner is not the problem — the anchoring and the clearance are. Do not treat this section as a no-op: the portal (A1), the z-index (A3) and the safe-area offsets below all still apply.

Launcher: replace fixed bottom-6 right-6 z-50 with fixed z-40 plus a style prop — Tailwind arbitrary values containing env() are unreliable, so set the offsets inline:

jsx
style={{
  right: 'calc(env(safe-area-inset-right, 0px) + 1rem)',
  bottom: 'calc(env(safe-area-inset-bottom, 0px) + 1rem)',
}}

Panel: keep the desktop anchor at sm:bottom-6 sm:right-6, and apply the same safe-area style so it tracks the launcher.

A3. Fix the z-index collision

z-50 is what shadcn's Dialog and Sheet overlays use, so today the stacking order is decided by DOM order rather than intent. Add a scale to client/src/index.css and use it:

css
:root {
  --z-sidebar: 30;
  --z-chat:    40;
  --z-modal:   50;
  --z-toast:   60;
}

Launcher and chat panel go to z-40 — above page content, sidebar and header; below modals and toasts. Do not raise the launcher above dialogs: a chat button floating over a confirmation dialog reads as a bug.

A4. Add a dismiss X to the launcher
Small circular button pinned to the launcher's top-right, e.g. absolute -top-1 -right-1 h-6 w-6 rounded-full border bg-muted text-muted-foreground.
The hit area must be at least 44×44 CSS px — use transparent padding around the glyph, not a bigger glyph.
e.stopPropagation() on click so it never opens the chat.
aria-label="Hide support chat", real <button>, visible focus ring, data-testid="button-support-hide".
Persist to localStorage under unihub.support.launcherHidden.v1. Wrap both read and write in try/catch — storage throws in some private-mode contexts.
A way back is mandatory. Add a "Support" entry to the sidebar menu that clears the flag and restores the launcher. Do not ship the X without it.
Hide the launcher only. Do not unmount the widget or discard unread state.
A5. Do not render the launcher on /scan

That is a kiosk screen — and the bottom-right corner is exactly where a thumb rests while scanning.

A6. Mobile panel safe areas

The open panel is fixed inset-0 on mobile. Add safe-area padding to its header and its input row so the close button clears the notch and the input clears the home indicator.

A7. Replace 100vh in the panel

sm:max-h-[calc(100vh-3rem)] → sm:max-h-[calc(100dvh-3rem)].
